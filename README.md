# Fundamentos de Computação em Nuvem

Este repositório contém as notas de estudo, resumos e atividades desenvolvidas como parte do curso Fundamentos de Computação em Nuvem, oferecido pela Escola da Nuvem.

O material aqui reunido vai além das aulas, incluindo anotações e sínteses elaboradas para fixar o conteúdo e servir como base de consulta contínua sobre a infraestrutura e os serviços em nuvem.

Este conteúdo faz parte da minha preparação para a certificação AWS Certified Cloud Practitioner, incluindo mapas mentais sobre os principais tópicos da prova.
